# Production RAG

Production-oriented RAG system with hybrid retrieval,
reranking, grounded generation and citation verification.

## Goal

Build a production-grade RAG system over internal company documentation.

## Stack

- Python
- FastAPI
- Qdrant
- BM25
- Embeddings
- LLM
- Docker
